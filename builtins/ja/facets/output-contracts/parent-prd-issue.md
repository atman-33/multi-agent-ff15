## Format

````markdown
---
prd_key: <same key as requirements brief>
issue_number: <github issue number>
issue_url: <absolute github issue url>
issue_title: <github issue title>
issue_action: <create or update>
---
````

## Rule

- `prd_key` は `requirements-brief.md` と `prd-draft.md` の `PRD Key` と一致させること
- `issue_number` は数値のみで記録すること
- `issue_url` は GitHub issue の absolute URL にすること
- `issue_title` は publish 済みの GitHub issue title と一致させること
- `issue_action` は `create` または `update` のどちらかにすること

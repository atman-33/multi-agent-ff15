## Format

````markdown
---
change_name: mission-scoped-output-contracts
change_path: /home/atman/repos/multi-agent-ff15/openspec/changes/mission-scoped-output-contracts
---
````

## Rule

- `change_name` は必須で、作成した OpenSpec change directory 名と一致させること
- `change_path` は推奨で、指定する場合は OpenSpec change directory への workspace absolute path と一致させること

# Fix Code — 手順指示

## 手順

1. **レビュー報告を読む**
   - 前の movement の code review findings を確認する
   - 対応必須の **blocking** finding をすべて洗い出す
   - 任意改善として non-blocking finding も把握しておく

2. **修正方針を立てる**
   - 各 blocking finding に対して適切な修正方法を決める
   - その修正で新たな問題が入らないことを確認する
   - finding が誤りまたは非該当なら、その理由を記録する

3. **修正を適用する**
   - severity の高い順に各 blocking finding に対応する
   - 最小限かつ焦点化した変更にとどめ、レビューで指摘された点だけを直す
   - 修正によって振る舞いが変わる場合はテストも更新する

4. **自己検証する**
   - 型チェックを実行し、すべてのエラーを解消する
   - lint を実行し、すべての警告を解消する
   - すべてのテストを実行し、必ず通す
   - 各 blocking finding を再確認し、解消されたことを確認する

5. **報告する**
   - 各 blocking finding について、finding_id、適用した修正、検証結果を報告する
   - 修正できなかった finding があれば、理由を説明して blocked と明記する
   - 適切なステータスタグを出力する

## 重要ルール

- すべての blocking finding に対応すること。ひとつも飛ばさない。
- non-blocking finding は、ごく軽微（同じファイル・同じ行付近）でない限り直さない。
- blocking finding を解消できない場合は、説明付きで abort のステータスタグを出力する。
- 変更は最小限にとどめ、レビュー要求を超えるリファクタリングや改善はしない。

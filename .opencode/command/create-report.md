description: Create a supplementary report in multi-agent-ff15/docs/reports with required frontmatter.
---

1. Create or update a Markdown report in `multi-agent-ff15/docs/reports/`.
2. Add YAML frontmatter with `title`, `author`, `date`, and `tags`.
3. Use an English title and English body unless the user requests another language.
4. Use a clear kebab-case filename that matches the report purpose.
5. Never write reports to the target repository.

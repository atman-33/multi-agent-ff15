# Documentation Format Template

<!-- Standard structure for design and technical documents. Write in clear, concise English. -->

1. Title
   - Short, descriptive title

2. Purpose / Summary
   - One-paragraph summary: what this document covers and why it exists.

3. Scope
   - What is included and excluded.

4. Background / Context
   - Relevant history, related changes, decisions.

5. Design / Architecture
   - High-level architecture diagrams or ASCII diagrams
   - Components and responsibilities
   - Data flow and interaction patterns

6. API / Interface
   - Public interfaces, endpoints, input/output contracts, example requests/responses

7. Usage / Examples
   - How to use the feature, sample commands, code snippets

8. Migration / Backwards-compatibility
   - Migration steps, versioning, compatibility constraints

9. Testing / Verification
   - How to test (manual and automated), test data, expected results

10. CI / Deployment
   - Build, deployment steps, required checks, rollout plan

11. Security / Privacy
   - Threat model, protections, data handling notes

12. Operational Considerations
   - Monitoring, alerts, runbook links

13. Changelog
   - Short history of document updates with dates and authors

14. Appendices / References
   - Links to related docs, RFCs, tickets
